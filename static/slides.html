Chunking — Prose / Policy Pages

Split where meaning shifts

  • 1
    Tokenize into sentences with NLTK, embed each with all-MiniLM-L6-v2
  • 2
    Compute cosine similarity between adjacent sentences. Find boundaries where similarity drops below the 25th percentile — adaptive threshold, not fixed.
  • 3
    Merge chunks smaller than 200 chars to avoid noise fragments.
# chunking.py — built from scratch embeddings = model.encode(sentences) similarities = [ cosine(embeddings[i], embeddings[i+1]) for i in range(len(sentences) - 1) ] threshold = np.percentile(similarities, 25) boundaries = [i for i, s in enumerate(similarities) if s < threshold]

Metadata — Department Tagging

Every chunk knows its department

  • 1
    First pass: scan all pages for course codes. Any page with codes → record its department using the existing prefix map (CS → Computer Science, ECE → Electrical Engineering…)
  • 2
    Forward-fill: pages without codes (intro, admission prose) look forward up to 15 pages to find the nearest department. Admission pages come before course descriptions — forward is the right direction.
  • 3
    No hardcoding — the prefix→department map is already used for course metadata. Reused here for prose chunks.
# pipeline.py — two-pass tagging for page in pages: for code in re.findall(r'[A-Z]{2,5}\s\d{3}', page["text"]): prefix = code.split()[0] if prefix in DEPT_MAP: page_dept[page["page"]] = DEPT_MAP[prefix] # nearest forward then backward, window=15 meta["department"] = nearest_dept(page_num)
